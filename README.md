## Overview

The **Luxury Hotel Reservation System** is a web-based application developed using **PHP, MySQL, HTML, CSS, and JavaScript** to simplify hotel room reservation and management. The system enables customers to view available rooms, make reservations, and manage booking details through an interactive and user-friendly interface.

The application reduces manual reservation processes by maintaining customer and booking information digitally. It provides efficient room management while improving the overall booking experience for both customers and administrators.

This project demonstrates the implementation of **Database Management System (DBMS)** concepts, including relational database design, CRUD operations, SQL queries, and web-based database connectivity using PHP and MySQL.

# Installation

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into the **htdocs** directory.
4. Import **database.sql** into phpMyAdmin.
5. Open your browser.
6. Navigate to:

```
http://localhost/Luxury-Hotel-Reservation-System/
```
